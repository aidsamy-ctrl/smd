Exercices GitHub

Apprendre à partager son code et travailler en équipe

1. Exercice GitHub / Push

  1. Créer un compte GitHub.
  2. Configurer sa clé SSH.
  3. Créer un dépôt public.
  4. Associer son dépôt local au dépôt distant.
  5. Envoyer sa branche master avec push.

2. Exercice GitHub / Clone

  1. Choisir un collègue de travail.
  2. Cloner son dépôt distant.
  3. Ajouter le collègue comme collaborateur.
  4. Ajouter son nom à la page des contacts et faire un commit.
  5. Envoyer les modifications avec push.
  6. Récupérer les modifications avec pull.

Attention : les identifiants du dernier commit doivent permettre d'identifier son auteur.

3. Exercice GitHub / Fetch

Sur son dépôt local

  1. Ajouter un commit sur la branche master.
  2. Envoyer les modifications avec push.

Sur le clone du dépôt du partenaire

  1. Créer une branche pour contribuer.
  2. Créer deux commits sur cette branche.
  3. Récupérer les modifications de la branche master distante.
  4. Vérifier les commits à intégrer.
  5. Fusionner la branche contenant sa contribution.
  6. Envoyer le résultat avec push.

4. Commandes Git utiles

  • git clone URL : cloner un dépôt.
  • git add . : ajouter les fichiers.
  • git commit -m "message" : créer un commit.
  • git push : envoyer les modifications.
  • git pull : récupérer les modifications.
  • git fetch : récupérer les changements distants.
  • git merge : fusionner une branche.
  • git log --oneline --all --graph : afficher l'historique.
